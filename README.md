## MPBOT

Discord Bot that asks AP-style physics and math questions.

## Getting Started

You can [click here](https://discord.com/oauth2/authorize?client_id=1468428833056231608&permissions=2048&integration_type=0&scope=bot) to invite your bot to the server.

### Using the bot

Use the slash command /physics and /math to get a question. Then you can choose a specific chapter/unit for that subject.

## Warning
This bot will not be supported or updated further. It runs on Gemini's free tier, 
which has a low daily/per-minute quota. If you see "Ran out of Gemini Limits :((" 
as the question text, that means the quota's been hit. It usually resets within a day.
